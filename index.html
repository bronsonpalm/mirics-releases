Prepare the downloads

You’ll need a Mac, an iPhone, a USB cable, Wi-Fi, and your own Apple Account for the first setup. If SideStore is already installed and refreshes successfully, continue to step 4.

Open this same address on your Mac to download the setup helper:

bronsonpalm.github.io/mirics-releases

Switch this guide to On Mac there. Keep this page open on your iPhone for the phone steps.

Download and unzip the Mac setup package. Keep its files together, then double-click Set up Mirics.command.

Download Mac setup

The helper downloads the latest Mirics app, checks its size and SHA-256 checksum, and opens the verified official installer, iloader. Finder highlights the verified Mirics.ipa as a fallback.

The helper uses macOS tools. You don’t need Xcode or Python. It opens Terminal; sign in only inside iloader and SideStore.

You approve Apple’s sign-in and security prompts yourself. The helper does not silently install phone apps or change your security settings.

If the Mac helper won’t open

Follow the official SideStore installation guide and get iloader from its official website. Don’t disable your Mac’s security protections.

Mac and iPhone

Set up SideStore

  1. Connect your unlocked iPhone to the Mac with a cable. Tap Trust if asked.
  2. In iloader on the Mac, sign in with your own Apple Account, select your iPhone, and choose Install SideStore (Stable).
  3. On iPhone, go to Settings → General → VPN & Device Management and trust the developer entry for that Apple Account. If shown, choose Allow & Restart, enter your passcode, and unlock the phone afterward.
  4. Enable Settings → Privacy & Security → Developer Mode if required. Restart and confirm, then reconnect LocalDevVPN.
  5. Open SideStore. Sign in with the same Apple Account you used in iloader.
  6. Open My Apps and tap SideStore’s own 7 DAYS counter. If asked about a signing certificate, follow SideStore’s confirmation. Wait for this first refresh to succeed.
Open SideStore

Finish SideStore’s first refresh before installing Mirics. Mirics must appear in SideStore’s My Apps so SideStore can renew it.

On your iPhone

Install Mirics

After SideStore’s first refresh succeeds, keep Wi-Fi and LocalDevVPN connected. The install button asks SideStore to download the latest Mirics app.

Install Mirics with SideStore

Open this page on your iPhone, select On iPhone, then use Install Mirics with SideStore.

Confirm installation in SideStore. Keep app extensions if asked; they display the lyrics. Check that Mirics appears in My Apps and refreshes successfully.

If the install button doesn’t open SideStore

On iPhone, download Mirics.ipa and save it to Files. In SideStore → My Apps → +, select the file. You can also AirDrop the verified Mirics.ipa from the Mac helper to the iPhone and save it in Files.

If SideStore is missing, return to step 3. Don’t install Mirics directly through iloader; install it from SideStore so renewal is managed there.

Already have Mirics in SideStore and a successful refresh? Keep that installation and continue. The button uses SideStore’s documented install link.

Connect Spotify and CarPlay
  1. In Mirics, enter your Spotify developer Client ID, tap Connect Spotify, sign in, and approve access. Spotify setup in the app explains how to get a Client ID. This connection uses Spotify Premium.
  2. Allow While Using App location access when Mirics asks. It is used by the current drive mode to keep syncing in the background; a website cannot grant it.
  3. In Shortcuts, create Automation → + → CarPlay → Connects. Choose Run Immediately, add Mirics’s Start lyrics action, and save.
  4. Create another CarPlay automation for Disconnects, with Run Immediately and Mirics’s Stop lyrics action.
  5. Keep Auto-connect on in Mirics. Lyrics use the CarPlay Dashboard on iOS 26 or later. If the card is missing, check Settings → Apps → Mirics → Live Activities.
Add the complete refresh shortcut

The complete shortcut checks for Mirics updates, installs a new version when available, renews your apps, and disconnects the VPN afterward.

Add Mirics Refresh
  1. On iPhone, open the download in Shortcuts and tap Add Shortcut. If Safari saves the file instead, open Mirics Refresh.shortcut from Files to import it.
  2. Allow the shortcut to use LocalDevVPN, Mirics, and SideStore when Shortcuts asks. The included LocalDevVPN actions turn its VPN on and off.
  3. Keep its name Mirics Refresh. If you already have an older copy, replace that copy when Shortcuts asks so the daily automation keeps the same target.

If an app action is unavailable, open LocalDevVPN, Mirics, and SideStore once and try again. Use the latest LocalDevVPN from the App Store for its built-in shortcut actions. Follow the official SideStore guide if its actions are still missing.

What the shortcut does

All eight actions are included. This is a reference for checking the imported shortcut:

Enable LocalDevVPN Wait Get Mirics update (verified file) If update result has any value Install IPA: update result End If Refresh All Apps Disable LocalDevVPN

Keep Mirics’s Auto-update setting on for new-version checks. When Mirics is current, installation is skipped and renewal continues.

Test and make it daily
  1. Run Mirics Refresh once on Wi-Fi with the phone unlocked. Check that renewal succeeds and LocalDevVPN disconnects. If the shortcut stops with an error, check the error and disconnect the VPN yourself.
  2. In Shortcuts, choose Automation → + → Time of Day → Daily. Pick a time when Wi-Fi is available, choose Run Immediately, and select Mirics Refresh.
  3. If you already have that daily automation, keep it. You don’t need a duplicate.

Updates are checked when the shortcut runs. Installing a new version may require an unlock or confirmation; fully unattended installation while locked has not been verified. Your Mac can be off after setup, but keep SideStore, LocalDevVPN, and the automation on the iPhone.

On your computer

Get iloader for free

You need a Mac or Windows computer, your iPhone, a USB cable, Wi-Fi, and your own Apple Account for the first setup.

  1. Open this address on your computer: bronsonpalm.github.io/mirics-releases.
  2. Select On computer at the top of that page.
  3. Follow the download steps there.

Keep this page open on your iPhone for the next steps.

If you have a Mac:

  1. Download iloader for Mac.
  2. Open the downloaded .dmg file.
  3. Drag iloader into Applications.
  4. Open iloader.

If you have Windows:

  1. Install iTunes from Apple if you do not already have it.
  2. Download iloader for Windows.
  3. Run the downloaded .exe installer.
  4. Open iloader.

iloader is free. A donation is optional; these links go directly to its official downloads.

Optional Mac download helper

The Mirics Mac setup package downloads iloader and the latest Mirics file for you. Unzip it, keep its files together, then open Set up Mirics.command. It checks the app download’s size and SHA-256 checksum. You still approve the installation and Apple Account prompts yourself.

If you use this helper, continue with the same iPhone steps below. You do not need Xcode or Python.

Get LocalDevVPN

  2. Install LocalDevVPN from the App Store.
  3. Open LocalDevVPN.
  4. Tap Connect.
  5. Allow the VPN configuration when your iPhone asks.
Get LocalDevVPNOpen LocalDevVPN

Use LocalDevVPN 1.3.0 or later. It only needs to be connected while SideStore installs, updates, or refreshes apps. The refresh shortcut will turn it on and off for you.

Computer and iPhone

Connect your iPhone

  1. Unlock your iPhone and keep it unlocked.
  2. Connect it to your computer with a USB cable.
  3. Tap Trust on your iPhone if asked.
  4. Enter your iPhone passcode to confirm.
  5. Open iloader on the computer.
  6. Check that your iPhone appears in iloader’s device list.

If your iPhone is missing, unlock it, reconnect the cable, and check for a Trust prompt. Choose Refresh Devices in iloader, then check its device list again. Try a USB cable that supports data. On Windows, make sure iTunes from Apple is installed.

Official connection requirements

In iloader on your computer

Install SideStore with iloader

  1. Sign in to iloader with your own Apple Account.
  2. Enter your Apple verification code if asked.
  3. Select your iPhone in iloader.
  4. Choose SideStore (Stable) under Installers.
  5. Keep the iPhone connected while iloader installs SideStore and sets up pairing.
  6. Wait until iloader reports that installation finished.

Remember which Apple Account you use here. You will use that same account inside SideStore. Enter your password only into iloader or SideStore, never into this website.

If iloader won’t sign in
  1. In iloader on your computer, scroll down to Settings below Installers.
  2. Open the Anisette Server menu.
  3. If your current server is different, choose Jkcoxson (Mac), with the address https://mac-ani.jkcoxson.com.
  4. If that preset is missing, choose Use custom Anisette server and enter https://mac-ani.jkcoxson.com.
  5. Return to the Apple Account sign-in area and try signing in once.
  6. Enter your Apple verification code if asked.
  7. After sign-in succeeds, select your iPhone and choose SideStore (Stable).

The server choice saves automatically. Jkcoxson (Mac) also works from Windows. If it is already selected or unavailable, try another listed server. Leave the server unchanged when sign-in works.

These are iloader’s settings on the computer. SideStore has its own server settings on the iPhone, covered later. Server names can vary by iloader version. Official iloader server-change release notes

iloader handles pairing during this installation. Do not disconnect the cable yet. Official SideStore installation steps

On your iPhone

Allow development apps

  1. Open Settings → General → VPN & Device Management.
  2. Trust the developer entry for the Apple Account you used in iloader.
  3. Choose Allow & Restart if shown.
  4. Open Settings → Privacy & Security → Developer Mode.
  5. Turn Developer Mode on.
  6. Restart your iPhone when asked.
  7. Confirm Developer Mode after the restart.

Already trusted and enabled? Continue. Developer Mode must stay on for your SideStore apps to run.

In SideStore on your iPhone

Sign into SideStore

  1. Unlock your iPhone and connect it to Wi-Fi.
  2. Open LocalDevVPN and connect it.
  3. Open SideStore.
  4. Choose Sign In if SideStore is not already signed in.
  5. Use the same Apple Account you used in iloader.
  6. Enter your Apple verification code if asked.
  7. Wait for SideStore to finish signing in.
Open SideStore

Signed in successfully? Skip the two troubleshooting pages. If you see an error such as -80045 or 45061, choose Next step for the fixes that worked on the tested iPhone.

Official SideStore sign-in help

Optional · only if sign-in fails

Choose a different sign-in server

  1. Open SideStore → Settings.
  2. Scroll down and turn On-Device Anisette off if it is shown. In newer versions, look under User Customizations.
  3. Close and reopen SideStore if Anisette Servers is missing.
  4. Open Settings → Anisette Servers.
  5. Only if SideStore keeps changing your selected server, turn Enable Auto Rotation off in Customization.
  6. Select the jkcoxson server with the address https://mac-ani.jkcoxson.com.
  7. Return to Sign In and try signing in once with the same Apple Account.

Leave Auto Rotation as it is if your server selection stays put. This server change helped on the tested iPhone; it is not a guaranteed fix. Menu names can vary by SideStore version. jkcoxson is independently operated and appears in SideStore’s maintained server list. If it is unavailable, choose another supported server from SideStore’s list.

Still seeing 45061 or another sign-in error? Continue to the next page. Official anisette server guide · SideStore’s maintained server list

Optional · only if errors remain

Reset SideStore’s sign-in data

This was the final step that resolved 45061 on the tested iPhone. Use it only if changing the server did not let you sign in.

  1. Open SideStore → Settings → Anisette Servers.
  2. Find Troubleshooting → Reset adi.pb. If it is not there, check Settings → User Customizations.
  3. Choose Reset & Sign Out.
  4. Return to SideStore’s sign-in screen.
  5. Sign in once with the same Apple Account you used in iloader.
  6. Enter your Apple verification code if asked.

This clears SideStore’s local sign-in data and signs you out of SideStore. It does not sign your iPhone out of its Apple Account. It is not a pairing-file reset; do not delete pairing files for these steps.

If the error remains, keep its exact code and use SideStore’s official troubleshooting help before installing Mirics. Repeating sign-in attempts is not required.

On your iPhone

Refresh SideStore once

  1. Unlock your iPhone.
  2. Reconnect LocalDevVPN.
  3. Open SideStore.
  4. Open My Apps.
  5. Tap SideStore’s own days-remaining counter, such as 7 DAYS, to refresh it.
  6. Wait for the refresh to finish successfully.
Open SideStore

Complete this refresh before installing Mirics. If SideStore asks you to confirm its signing certificate, follow its prompt. If you are signed out, return to the Sign into SideStore page first.

In Mirics on your iPhone

Connect Spotify

  1. Open Mirics.
  2. Tap Connect Spotify.
  3. Sign in with your own Spotify account.
  4. Approve Spotify’s access request.
  5. Choose Allow While Using App if Mirics asks for location access.
  6. Play a song in Spotify.
  7. Return to Mirics.
  8. Tap Start lyrics if shown.
Open Mirics

The Spotify connection is included. You do not need to create or type a Client ID. If Spotify denies access, ask the Mirics owner to add your Spotify account to the app’s user allowlist. The owner needs Spotify Premium; this setup supports up to five allowlisted users.

Current drive mode uses location to keep lyrics syncing in the background. If the lyrics card is missing, allow Settings → Apps → Mirics → Live Activities. CarPlay Dashboard lyrics require iOS 26 or later.

Try one CarPlay automation

Experimental: update to Mirics build 23 or later, then test this on your actual iPhone and car before replacing the two separate automations. Real-car operation has not been verified.

  1. Tap Add Mirics CarPlay below. Shortcuts opens the premade shortcut.
  2. Tap Add Shortcut. Choose Replace if asked and keep its name Mirics CarPlay.
  3. While parked, temporarily turn off your old CarPlay Connects and Disconnects automations.
  4. Open Shortcuts → Automation → + → CarPlay.
  5. Select both Connects and Disconnects.
  6. Select Run Immediately, then choose the saved Mirics CarPlay shortcut.
  7. Save and leave Auto-connect on in Mirics.
  8. Connect to CarPlay and play a song. Check that lyrics start, including with the phone locked. Test pausing music too.
  9. Disconnect CarPlay and check that the lyric card closes.
  10. If either event fails, turn off the combined automation and turn your old two back on.

Add Mirics Refresh

Open this page on your iPhone and choose On iPhone to download the shortcut.

This is the complete shortcut. Its refresh, update, and VPN actions are already included. Keep its name Mirics Refresh; you do not need to build or edit it.

If the shortcut does not open

Open Files → Downloads → Mirics Refresh.shortcut. If an app action is unavailable, open LocalDevVPN, Mirics, and SideStore once, then try again. Use LocalDevVPN 1.3.0 or later.

What the shortcut does

Enable LocalDevVPN Wait Get Mirics update (verified file) If update result has any value Install IPA: update result End If Refresh All Apps Disable LocalDevVPN

Leave Auto-update on in Mirics to check for new versions. If Mirics is already current, installation is skipped and renewal continues.

Setup complete

Try your lyrics

  1. Open Spotify to test your auto-start automation.
  2. Play a song that has timed lyrics.
  3. Check the Mirics lyrics card on your Lock Screen.
  4. Connect to CarPlay to test its automation when you next use your car.
Open Mirics

Your computer can be off after setup. Keep SideStore, LocalDevVPN, the Mirics Refresh shortcut, and its daily automation on your iPhone.

iOS controls background execution, so uninterrupted watching is not guaranteed. If lyrics stop, open Mirics and start them again. Some songs do not have timed lyrics.
